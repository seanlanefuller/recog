# Recog - Voice Recognition

A simple, lightweight web application for voice-to-text recognition using the Web Speech API.

## Features

- **Real-time Recognition**: Converts spoken words into text instantly.
- **Continuous Mode**: Keeps listening and updating the transcript as you speak.
- **Clean Interface**: Minimalist dark-themed UI for focused use.

## How to Use

1. Open `recog.html` in a supported browser (e.g., Chrome or Edge).
2. Click the **Start** button to begin recognition.
3. Your spoken words will appear in the text area.
4. Click **Stop** to end the session.

## Browser Support

- Google Chrome
- Microsoft Edge
- Other browsers supporting the `Web Speech API`.
